# Contributing to JULIUS

Thank you for your interest in contributing to JULIUS.

JULIUS is an educational AI project focused on programming education, logical thinking and teacher-supervised assessment.

## Ways to contribute

Contributions may include:

- bug fixes;
- documentation improvements;
- classroom-use examples;
- accessibility improvements;
- translations;
- pedagogical activities;
- evaluation rubrics;
- reproducible experiments;
- code improvements;
- research replication materials.

## Contribution workflow

1. Open an issue describing the proposed change.
2. Explain the educational or technical motivation.
3. Fork the repository.
4. Create a dedicated branch.
5. Make the change with clear commit messages.
6. Submit a pull request.
7. Describe how the change was tested and how it affects teaching or learning.

## Educational responsibility

Contributions involving automated feedback or assessment should preserve human supervision. JULIUS should support teacher judgment, not replace it.

## Research contributions

If your contribution is linked to an experiment, classroom deployment or publication, include enough methodological information for others to understand and reproduce the work.

## Code of conduct

Contributors are expected to communicate respectfully and constructively in issues, discussions and pull requests.

## Intellectual property

Only contribute material that you have the right to distribute. Do not upload copyrighted courseware, student information, proprietary institutional material or third-party assets without appropriate permission.

## Student privacy

Never include personally identifiable student data, grades, institutional credentials, private datasets or classroom records in public contributions.
